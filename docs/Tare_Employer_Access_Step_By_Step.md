# Tare Employer Access: Maddie’s Step-by-Step Guide

This guide explains how to create an employer campaign, invite candidates, and give an employer access to its completed reports.

## The three doors

Tare now has three separate doors. Each door is for a different person.

### Door 1: Maddie’s private Tare dashboard

**Who uses it:** Maddie only.

**Page:** [Maddie’s Tare Research Dashboard](https://tare-weigh-station.workspace-535676.chatgpt.site/beta-admin.html)

**Maddie’s administrator code:** `2140`

Use this dashboard to:

- See all beta reports.
- Create employer campaigns.
- Generate company access codes.
- Generate candidate invitation links.

Do not give employers the `2140` code. It opens Tare’s master research dashboard.

### Door 2: The Employer Portal

**Who uses it:** Employers.

**Page:** [Tare Employer Portal](https://tare-weigh-station.workspace-535676.chatgpt.site/employer-portal.html)

Employers do **not** use `2140`.

Every employer receives its own company access code. That code allows the employer to see only its own campaigns, candidates, and reports.

Employers can also reach this page by selecting **Employer Login** on the [main Tare website](https://tare-assessment.workspace-535676.chatgpt.site).

### Door 3: A candidate’s assessment invitation

**Who uses it:** One specific candidate.

Every candidate receives a different invitation link. The link automatically tells Tare:

- Which company invited the candidate
- Which hiring campaign the candidate belongs to
- Which position the candidate is being considered for
- Which candidate reference should label the report

Do not send one candidate another candidate’s link.

# Part One: Create an employer campaign

## Step 1: Open your private dashboard

Open [Maddie’s Tare Research Dashboard](https://tare-weigh-station.workspace-535676.chatgpt.site/beta-admin.html).

## Step 2: Enter your administrator code

Enter:

`2140`

Then select **Open reports**.

If `2140` does not work:

1. Confirm that you opened **Maddie’s Tare Research Dashboard**, not the Employer Portal.
2. Refresh the page.
3. Enter `2140` again without spaces.

## Step 3: Find “Create an employer campaign”

At the top of your dashboard, find the section called:

**Create an employer campaign**

## Step 4: Enter the company information

Complete these boxes:

- **Company name:** The employer’s company or law-firm name.
- **Campaign name:** The name of this hiring round.
- **Role or position:** The job for which candidates are being assessed.

Example:

```text
Company name: Happy Law Firm
Campaign name: Summer 2027 Hiring
Role or position: Summer Associate
```

## Step 5: Enter the candidates

Enter one candidate on each line.

Use this format:

```text
Candidate reference | Candidate name
```

Example:

```text
CAND-001 | Maya Chen
CAND-002 | Jordan Lee
CAND-003 | Avery Williams
```

The candidate reference can be any unique label the employer understands. Avoid using highly sensitive information.

## Step 6: Create the campaign

Select:

**Create access and invitations**

Tare will generate:

1. One Employer Portal address
2. One company access code
3. One unique invitation link for every candidate

## Step 7: Save the information immediately

The company access code is shown when the campaign is created. Copy it somewhere safe immediately.

Keep these items together:

- Company name
- Campaign name
- Employer Portal address
- Company access code
- Candidate names and references
- Candidate invitation links

# Part Two: Send the employer its access information

Send the employer:

1. The [Tare Employer Portal](https://tare-weigh-station.workspace-535676.chatgpt.site/employer-portal.html)
2. Its unique company access code
3. A reminder not to share the code outside its authorized hiring team

Example message:

> Your Tare Employer Portal is available here:  
> https://tare-weigh-station.workspace-535676.chatgpt.site/employer-portal.html  
>
> Your company access code is: TARE-XXXX-XXXX  
>
> This code opens only your organization’s campaigns and candidate reports. Please keep it within your authorized hiring team.

Do not send the employer:

- Maddie’s private dashboard link
- The `2140` administrator code
- Another employer’s access code
- Another employer’s candidate reports

# Part Three: Send each candidate the correct invitation

Every candidate receives their own generated assessment link.

Before sending a link, match:

- Candidate name
- Candidate reference
- Position
- Campaign
- Invitation link

Example:

- Send Maya the link labeled `CAND-001 | Maya Chen`.
- Send Jordan the link labeled `CAND-002 | Jordan Lee`.

The candidate opens the link and sees the company, campaign, position, and candidate reference before beginning.

The candidate then:

1. Completes the 30-question Weigh Station assessment.
2. Submits the assessment.
3. Receives a personal tester ID.
4. Uses that tester ID to access the participant-safe recap.

The candidate does not receive the confidential employer report.

---

# Part Four: What happens after a candidate finishes

When the candidate submits:

1. Tare recognizes the candidate’s invitation.
2. Tare connects the submission to the correct company.
3. Tare connects it to the correct campaign and position.
4. Tare labels it with the candidate’s name and reference.
5. The report appears in that company’s Employer Portal.

The employer does not need the candidate’s tester ID to locate the report.

---

# Part Five: How an employer reads a report

The employer:

1. Visits the [main Tare website](https://tare-assessment.workspace-535676.chatgpt.site).
2. Selects **Employer Login**.
3. Enters its unique company access code.
4. Opens its assessment roster.
5. Finds the candidate using the name, reference, position, campaign, completion date, or Tare report ID.
6. Selects the completed candidate report.

The employer sees only reports connected to its company code.

The roster also shows candidates who have not completed their invitations yet.

# Part Six: How Maddie reads all beta reports

To see the master research collection:

2. Enter `2140`.

This dashboard includes independent beta submissions and employer-connected submissions.

Never direct an employer to this master dashboard.

# Quick troubleshooting

## “2140 does not work”

You are probably on the Employer Portal.

Use `2140` only here:

https://tare-weigh-station.workspace-535676.chatgpt.site/beta-admin.html

## “The employer’s code does not work”

Confirm that:

- The employer is using the Employer Portal.
- The code was copied exactly.
- There are no extra spaces.
- The employer is using the code for the correct company.

## “The employer cannot find a candidate”

Check whether:

- The correct invitation link was sent.
- The candidate completed and submitted the assessment.
- The employer is using the correct company code.
- The candidate is listed as **not started** or **completed** in the roster.

## “A candidate opened the wrong company or name”

Do not let the candidate continue. Create or send the correct invitation link before the assessment is completed.

## “An employer asks for 2140”

Do not provide it.

Explain that `2140` is Tare’s internal administrator code. The employer must use its own company access code.
