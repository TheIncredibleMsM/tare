# Tare

Work-in-progress archive for Tare — the web app, the earlier weigh-station
prototypes, the investor pitch materials, and the working docs.

**Status: work in progress.**

## Layout

- `app/` — the current full-stack app (Next.js on vinext, Cloudflare D1 + Drizzle).
  See `app/README.md` for how to run it.
- `prototypes/` — standalone weigh-station HTML builds, earliest to latest
- `pitch/` — 3-minute investor pitch decks (`.pptx` / `.key`) and the script + Q&A
- `docs/` — continuation briefs, next-phase objectives, scenario banks, employer
  access walkthrough
- `assets/` — logo, logo studies, ambience audio loops, screenshots
